A small kit. A clear choice.

Start with the tools your project needs. Keep installation in your terminal and the evidence within reach.

  1. Find a resource

    Search the catalog and filter by category, client, or review status. Open a resource to see its compatibility, source, and recorded risks.

  2. Run its command

    Run from your Kit 3 checkout. Add --target /path/to/project to choose the project; otherwise the current directory is used. Mapped skills use the native skills installer. Other resources open a manual guide. The website never executes commands.

  3. Read the evidence

    A review describes what was checked. “Not reviewed” means there is no dossier; “Known risks” names unresolved findings. The catalog is a starting point for your decision.
