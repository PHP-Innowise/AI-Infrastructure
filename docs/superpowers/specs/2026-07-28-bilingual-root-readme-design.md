# Английский и русский корневые README

## Цель

Создать две явно названные полные языковые версии документации и оставить
корневой `README.md` короткой точкой выбора языка.

## Файлы

- `README.md` — короткий выбор языка, который GitHub показывает автоматически.
- `README_EN.md` — полная английская версия.
- `README_RU.md` — полная русская версия, основанная на текущем `README.md`.

Корневой файл содержит только название проекта и две ссылки:

```text
# PHP AI Accelerators
English | Русский
```

Обе полные версии также начинаются с переключателя. В английском файле
активным текстом без ссылки будет `English`, в русском — `Русский`. Второй
язык будет относительной ссылкой на соседний полный README.

## Содержание

Обе версии сохраняют одинаковую структуру и фактические утверждения:

1. назначение репозитория и состав редакций;
2. выбор и подключение Laravel, Symfony или PHP Core;
3. модель `Command → Agent → Skill`;
4. поддержка Claude Code, Cursor и Codex;
5. различия редакций;
6. Memory Bank и источники истины;
7. четыре слоя локального Context Engine;
8. полный CLI-сценарий `start → update → context → complete`;
9. безопасность, локальность данных и отсутствующие возможности;
10. проверенный Bauherrenmappe-сценарий;
11. Infrastructure Creator;
12. правила внесения изменений.

Английский README будет естественным техническим текстом, а не дословным
переводом русских конструкций. При этом команды, пути, числовые результаты,
ссылки и границы реализации должны совпадать.

## Источник истины для перевода

Текущий русский `README.md` сначала копируется в `README_RU.md`. Затем на его
основе создаётся `README_EN.md`, а `README.md` заменяется коротким
переключателем. Это сохраняет уже проверенные:

- безопасность `infra-scan` и подтверждение перезаписи в `infra-generate`;
- ссылки на Memory Bank каждой редакции;
- различие `tasks/` и `specs/`;
- точную семантику `context`, `search`, `complete` и `task-id`;
- рабочий пример поиска завершённого эпизода по `BAUMAS-133`;
- честные ограничения: отсутствие automatic per-request injection,
  embeddings, vector search, MCP, LangGraph и центрального сервиса памяти.

## Навигация

В полных версиях переключатель языка располагается перед заголовком
`# PHP AI Accelerators`. Он не меняет существующие якоря и относительные
ссылки на редакции.

Новые ссылки:

- из `README.md` в `README_EN.md` и `README_RU.md`;
- из `README_EN.md` в `README_RU.md`;
- из `README_RU.md` в `README_EN.md`.

## Проверка

Необходимо проверить:

1. переключатели в трёх файлах и все локальные Markdown-ссылки;
2. одинаковый набор основных разделов;
3. одинаковые команды, пути, ограничения и Bauherrenmappe-результаты;
4. соответствие команд текущему `context.py --help`;
5. отсутствие неподтверждённых возможностей в английской версии;
6. `git diff --check`;
7. 45 тестов и валидатор в каждой из трёх редакций.

## Границы

- Код, README редакций, Context Engine и changelog не меняются.
- Не добавляются генератор переводов, синхронизирующий скрипт или зависимость.
- Синхронизация языков остаётся обычной обязанностью при будущих правках
  корневой документации.
- Существующие `.langgraph_api/` и
  `ai_infrastructure_langgraph.egg-info/` остаются вне Git.
