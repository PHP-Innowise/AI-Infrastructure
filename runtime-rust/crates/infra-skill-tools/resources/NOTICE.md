# Attribution

Native Rust port of the bundled Anthropic skill-creator helpers from PHP Core/.agents/skills/skill-creator (also Laravel, Cms/wordpress and Symfony). Apache License 2.0 is retained in LICENSE.txt. The scaffold, improvement prompt wording and report styling derive from those vendored resources. Symfony's Codex/Cursor platform adaptation retains its distinct probe and failure semantics. The initializer creates a Rust example program in place of the former Python example. No bundled Python helper is invoked.

The interactive evaluation viewer is provided by the native infra-ui WebAssembly frontend; its resource generator must supply the selected frontend asset directory explicitly.
